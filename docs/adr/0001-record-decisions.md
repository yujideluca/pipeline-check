# ADR-0001: Record architecture decisions as ADRs

- **Status:** accepted
- **Date:** YYYY-MM-DD (project start)
- **Type (ISO/IEC/IEEE 14764):** initial
- **Decided by:** Giovanni (standard for all projects since 2026-10-22)

## Context

Without a record, in a year nobody knows why the structure is what it is, or which alternatives were already rejected.

## Decision

Structural decisions get an ADR here, in the same commit as the change. `DESIGN.md` keeps the one-line log.

## Alternatives considered

- **Only a decision log** — loses alternatives and which decision replaced which.

## Consequences

A short extra file per structural change; the monthly review checks for missing ones.
